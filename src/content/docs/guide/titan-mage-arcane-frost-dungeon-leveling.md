> 玩法定位：副本群怪升级、减少喝水时间、兼顾奥术爆炸与暴风雪。  
> 最终天赋：奥术 34 / 火焰 0 / 冰霜 37。

## 一眼看懂

这是一套副本特化的冰奥升级路线：先用冰霜天赋拿到完整的暴风雪减速，再用奥术爆炸触发「奥术专注」的节能施法，触发后施放不耗法力值的满级暴风雪。中期回到冰霜系补出寒冰护体和寒冰指，60级以后再深入奥术系，最终获得奥术潜能、奥术强化和咒术吸收。

## 适合与不适合

适合：

- 主要通过随机副本或固定队副本升级。
- 喜欢坦克聚怪后远程下雪，安全时贴身奥爆收尾。
- 更看重群体总伤、法力续航和少坐地板。

不适合：

- 追求最稳妥的野外单人升级。
- 队伍坦克经常移动拉怪，无法稳定聚成一团。
- 满级后直接进入团队副本。到达满级并获得基础装备后，应换成对应团本的正式输出天赋。

## 29级当前配点

29级共有20点天赋。此时应为 **7 / 0 / 13**，不要按80级终盘图随意拆点。

### 奥术 7点

- 奥术精妙 2/2
- 奥术集中 3/3
- 奥术专注 2/5

注意：「奥术集中」是浅层的命中与减耗天赋；「奥术专注」才是触发节能施法的5点天赋。

### 冰霜 13点

- 霜寒刺骨 3/3
- 凛冬帷幕 2/2
- 精准 2/3
- 极寒冰霜 3/3
- 强化暴风雪 3/3

「凛冬帷幕」是时光服新增天赋。2/2可以使冰霜法术造成的威胁值降低20%，适合坦克聚怪后的副本暴风雪场景。

## 副本实战手法

### 常规群怪

1. 等坦克完成第一轮聚怪和仇恨建立。
2. 怪群仍在移动或距离较远时，以满级暴风雪为主。
3. 怪群聚稳、坦克仇恨可靠时，靠近使用奥术爆炸触发节能施法。
4. 触发节能后立刻拉开距离，施放满级暴风雪。
5. 怪物残血且坦克仍能控制时，再用奥术爆炸收尾。

社区实战经验认为，时光服面对多个目标时更容易触发奥术专注，常见玩法是奥爆一至两次后接免费暴风雪。不过这不是无条件保证；没有触发时应根据剩余法力和坦克仇恨决定是否继续奥爆。

### 仇恨与保命

- 奥术爆炸必须等坦克聚稳后再用。连续贴身奥爆最容易因抢仇恨倒地。
- 坦克仍在拖动怪群时，不要随意冰霜新星。随机定身也可能让怪群前后脱节。
- 53级获得寒冰护体前，可在危险批次提前开法力护盾；获得寒冰护体后优先保持冰盾。
- 一旦怪物转向自己，停止奥爆，向坦克方向移动，并根据情况使用闪现、冰霜新星、冰锥术或急速冷却救场。

### 法力与雕文

- 优先学习最新等级的奥术爆炸和暴风雪。
- 冰霜导能 3/3 会降低所有法术的法力消耗，是中期续航核心。
- 核心大雕文推荐装配「奥术爆炸雕文」、「暴风雪雕文」与「唤醒雕文」，小雕文优先「缓落雕文」与「奥术智慧雕文」。
- 完整雕文分析与多路线对比可查阅：[泰坦重铸「时光」法师升级天赋与雕文推荐](/guide/titan-mage-leveling-talents-and-glyphs/)。
- 节能触发应尽量交给高消耗的满级暴风雪，不要被低价值法术提前消耗。
## 路线评价

这套34/0/37是高副本效率、低休息时间的特化方案，不是最稳的泛用冰法。它用一部分深冰控制和水元素能力，换取奥爆伤害、节能暴风雪、奥术强化和双盾触发咒术吸收的收益。

如果主要是野外单刷，标准深冰路线通常更安全；如果主要跟坦克刷副本，这套冰奥路线更贴近「速度就是强度」的目标。
